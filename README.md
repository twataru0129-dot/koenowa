# こえのわ

ひらがなの文字盤を一文字ずつタップして文章をつくり、端末の日本語音声で相手に伝える AAC（補助代替コミュニケーション）用の Web アプリ（PWA）です。iPhone の横向きでの利用を最優先にしています。縦向き、iPad、PC でも使えます。

- 文字盤は 3 ページです：① せいおん（10列×5段）、② だくおん・はんだくおん（5列×5段）、③ ちいさい文字・きごう
- 文字をタップしても音は出ません。「はっせい」を押すと文章全体を読み上げます
- 一度開いたあとは、通信なしでも起動・入力・編集ができます
- ログインは不要です。外部サービスも使いません。文章は端末の外へ送りません

## 画面と操作

| 場所 | 内容 |
|---|---|
| 文章エリア | 入力した文章を大きく表示します。文字をタップするとカーソルがそこへ移り、途中に挿入できます（端末のキーボードは開きません） |
| はっせい | 文章全体を読み上げます。読み上げ中にもう一度押すと、前の読み上げを止めてから最初から読みます（画面に「とめる」ボタンはありません） |
| 1文字けす | カーソルの直前の1文字を消します |
| もどす／やりなおす | 編集を1操作ずつ元に戻す／やり直します |
| ぜんぶけす | 確認してから全文を消します。「もどす」で元に戻せます |
| よくつかう | 登録した言葉の一覧です。タップするとすぐ発声します。入力中の文章は変わりません。「へんしゅう」に切り替えると、登録・なおす・並べかえ・けすができます |
| せってい | 声の選択（男性・女性・性別を判断できない声に分けて表示し、声ごとに試聴できます）、はやさ（とてもゆっくり 0.35／ゆっくり 0.6／ふつう 0.95／はやめ 1.15）、同じ文字の連続入力防止、よく使う言葉の自動登録 |
| ページ切り替え | 文字盤を左へなぞると次のページ（①→②→③→①）、右へなぞると前のページ（①→③→②→①）へ移ります。端のページから反対側へ循環します。下の左右の矢印ボタン（まえ／つぎ）も同じように循環します。●○○ を押すと、そのページへ直接移ります |

レイアウトは画面の形に合わせて変わります。

- **iPhone 横向き**：文章エリアと文字盤を左側に置き、操作ボタンは右側の列にまとめます。高さが足りないので、上下に積まずに横へ並べています
- **iPhone 縦向き／iPad／PC**：上から順に、文章、操作ボタン、文字盤、ページ切り替えを並べます

どのレイアウトでも、文字の並び順と空欄の位置は変わりません。

## 技術構成

- React 19 + TypeScript + Vite
- 読み上げ：ブラウザーの Web Speech API（`speechSynthesis`）
- 保存：`localStorage`（入力中の文章・カーソル・ページ、よくつかう言葉、設定のみ。会話の履歴は保存しません）
- PWA：`public/manifest.webmanifest` と、ビルド時に生成する Service Worker（`sw/sw.js` がテンプレートです）
- 外部 CDN、Web フォント、分析 SDK は使っていません

| ファイル | 役割 |
|---|---|
| `src/data/boards.ts` | 文字盤の確定配列（ここだけが配列の正本です） |
| `src/state/editor.ts` | 文章・カーソル・元に戻す（書記素単位で削除・移動） |
| `src/state/storage.ts` | 端末内保存と初期値 |
| `src/speech/speech.ts` | 読み上げ（重複防止、端末内の声を優先、オンラインの声は既定で使わない） |
| `src/components/Board.tsx` | 文字盤、スワイプ判定、誤入力の防止 |
| `src/components/TextDisplay.tsx` | 文章表示とタップによるカーソル移動 |
| `src/components/FavoritesPanel.tsx` / `SettingsPanel.tsx` | よくつかう言葉／せってい |
| `vite.config.ts` | ビルド設定と Service Worker の生成 |
| `scripts/make-icons.py` | 正式アイコン（`assets/official_icon.jpeg`）から各サイズのアイコンを生成します |
| `docs/` | 開発指示書とUI参考画像 |

## ローカルでの起動とビルド

Node.js 20 以上が必要です。

```sh
npm install
npm run dev        # 開発サーバー（http://localhost:5173）
npm run build      # 本番用ビルド（dist/ に出力）
npm run preview    # ビルド結果を確認（Service Worker も動きます）
```

テストは次のコマンドで実行します。

```sh
npm run typecheck  # 型チェック
npm run lint       # ESLint
npm test           # 単体・結合テスト（Vitest）
npm run test:e2e   # ブラウザーでの E2E テスト（Playwright / Chromium）
```

アイコンを作り直すときは `npm run icons` を実行します（Python 3 と Pillow が必要です）。

## iPhone で試す手順

2. **本番相当で試す**：GitHub Pages の公開URL（下記）を iPhone の Safari で開きます

### 端末の標準音声（自動）と音声の診断

- 「せってい」→「声」の一番上にある「端末の標準音声（自動）」を選ぶと、声を指定せず、日本語（ja-JP）だけを指定して読み上げます。どの声で話すかはブラウザー（iOS）が決めます。iPhone の「読み上げコンテンツ」で選んでいる声になる場合がありますが、保証はありません
- PC 版 Chrome など、日本語のオンラインの声が一覧にある環境では、オンラインの声が選ばれて文章が外部へ送られるおそれがあります。そのため、オンラインの声を許可していない限り、このモードは選べません
- 「せってい」の一番下にある「音声の診断（確認用）」を開くと、Web Speech API が返したすべての声（name / lang / voiceURI / localService / default）、総数、日本語の声の件数を確認できます。「コピー」で内容をコピーできます。入力した文章や登録した言葉は含みません

### 読み上げの自然さの調整（試験的）

どれも初期設定では今までと同じ読み方で、利用者が選んだときだけ使われます。

- **よくつかう言葉の「読み方」**：「へんしゅう」→「読み方」で、声に出すときだけ使う文章（読み上げ用テキスト）を設定できます。例：表示「きょうはいいてんきです」→ 読み上げ「今日はいい天気です。」。表示する文章は変わりません。空にするか「元の発声に戻す」で、いつでも元に戻せます。かなを漢字へ自動で変換することはしません
- **読み上げの比較（せってい）**：「従来」と「調整あり」を、例文・入力中の文章・よくつかう言葉で聞き比べられます。「調整あり」は読み上げ用の文字列の中だけで、空白を「、」に、句読点のない文の終わりに「。」を加えます。また、同じ句読点の連続を1つにまとめます。よくなければ「従来（標準）」に戻せます
- **はやさのこまかい調整（せってい）**：とてもゆっくり〜はやめ に加えて、0.30〜1.20 の範囲で調整できます。0.85〜1.05 の試聴ボタンで、設定を変えずに聞き比べられます
- どの方式でも、文章全体を1回の発声で読みます。声の高さ（pitch）は変えず、「端末の標準音声（自動）」もそのまま使えます

### よく使う言葉の自動登録

- 文字盤で入力してメイン画面の「はっせい」を押した言葉が10回になると、「よくつかう」に自動で追加し、上に短いお知らせを出します（初期値はオン。「せってい」で切り替えられます）
- 数えるのは「前回数えてから文字盤で文字を入力し、別の文章になったか、一度消して入力し直した」ときの発声だけです。同じ入力のまま何度「はっせい」を押しても1回です
  - 次の場合は数えません：「よくつかう」・試聴・比較からの発声、入力しただけ、カーソル移動・もどす・やりなおすだけの操作、起動後に保存から戻した文章をそのまま発声したとき
- 対象は40文字までの言葉です（前後の空白は除き、文中の空白は残して比べます）。空白だけ・記号だけの文章は数えません。すでに「よくつかう」にある言葉は数えず、手動で登録した言葉や読み上げ用テキストを上書きしません
- 端末内には、言葉ごとの回数と通し番号だけを最大200件保存します（日時や発声の一覧は保存しません）
- 「よくつかう」から消した言葉は、自動では登録しなおしません。その言葉を手動で登録するか、「せってい」の「自動登録の学習記録を消去」を行うと、また対象になります。消去しても「よくつかう」の言葉は消えません

### とてもゆっくり・一音ずつはっきり（試験的）

- 「とてもゆっくり」（0.35）は、文章全体を1回の発声で、速さだけを遅くして読みます。ほかの3段階の速さは変わりません
- 「一音ずつはっきり」（初期値は「つかわない」）を選ぶと、「とてもゆっくり」のときだけ、読み上げ用の文字列を音のまとまりごとに区切ります（例：あ、り、が、と、う／がっ、こ、う／しゃ、しん、を、み、せ、て）。区切りは「、」か空白から選べます。画面の文章は変わりません
- 「きょ」「しゃ」などの拗音、小さい「っ」、のばす音「ー」、「ん」は、前の音とまとめます。単独では読ませません
- 漢字・カタカナを含む文、「は」「へ」が言葉の途中にある文（こんにちは・おはよう・きょうは など）、24音を超える文は、読み方が変わるおそれがあるため区切らずに読みます

### ホーム画面に追加する

1. iPhone の Safari で、こえのわの URL を開きます
2. 画面下の共有ボタン（□↑）をタップします
3. 「ホーム画面に追加」を選び、名前が「こえのわ」になっていることを確かめて「追加」をタップします
4. ホーム画面のこえのわアイコンから起動します。ツールバーのない全画面で開きます

### 実機で確認してほしいこと

- [ ] 横向き・縦向きのどちらでも、すべてのキーが1画面に表示され、ノッチやホームバーに重ならない
- [ ] 縦向き（キー幅は約 32〜35px）で、狙ったキーを押せる。押し間違えが多くないか
- [ ] 文字盤を左右になぞったときにページが変わり、文字が勝手に入らない
- [ ] 「はっせい」で自然な日本語で読み上げられ、連打しても声が重ならない
- [ ] **機内モード**（Wi-Fi もオフ）で、ホーム画面から起動 → 入力 → 発声ができる
- [ ] 「せってい」で声の一覧に日本語の声が出て、「端末内」と表示される
- [ ] アプリを閉じて開き直すと、入力中の文章が戻っている

### 男性の声・高品質の声について

- こえのわに表示されるのは、ブラウザー（Web Speech API）から取得できた日本語の声だけです。取得できない声を、使える声として表示することはありません
- 性別は、名前から公表されている声（Kyoko・O-ren は女性、Otoya・Hattori は男性など）だけ分けます。名前から判断できない声は「性別を判断できない声」として名前だけで表示します
- 女性の声の高さを下げて男性の声に見せる処理はしていません
- 男性の声が一覧に出ないときは、次の手順で Otoya などの声をダウンロードし、こえのわを開き直してください。Siri の声は Web アプリからは使えません

より自然な声にするには、iPhone の「設定」→「アクセシビリティ」→「読み上げコンテンツ」→「声」→「日本語」から、拡張版やプレミアム版の声（例：Kyoko（拡張）、Otoya（拡張））をダウンロードし、こえのわの「せってい」で選んでください。

## 音声とオフラインについての注意

- 読み上げにはブラウザーの音声合成を使います。声の品質と、オフラインで使えるかどうかは端末と OS に依存します
- `localService: true`（「端末内」と表示される声）であっても、それだけでは完全なオフライン動作の保証になりません。実機で機内モードにして確認してください
- 端末内の日本語の声が見つからないときは、読み上げを行わずにその旨を表示します。オンラインの声（例：PC 版 Chrome の「Google 日本語」）は、文章がブラウザー提供元のサーバーへ送られる可能性があるため、既定では使いません。「せってい」で明示的に許可したときだけ使います
- PWA のキャッシュ（画面のオフライン起動）と、音声のオフライン可否は別のものです。それぞれ確認が必要です
